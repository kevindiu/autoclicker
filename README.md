## 🌟 專案簡介

**水滸歷險 巨集助手** 是一款專為《水滸歷險》玩家設計的自動化操作軟體。針對傳統連點程式常遇到的「搶奪滑鼠焦點」、「視窗位移即失效」、「連擊技能中斷」、「編輯巨集需重啟」等痛點進行全方位重構與升級。

本專案採用純 Python 與現代化 Tkinter 深色科技風介面打造，底層依託 Windows Win32 API 訊息機制（`PostMessageW`）實現真背景掛機，玩家可在掛機同時正常瀏覽網頁、辦公或觀看影片，體驗極致流暢與穩定。

---

## ✨ 核心特色

### 🎯 1. 真·背景掛機 (PostMessage Background Automation)
- 透過 Win32 底層 API 直接向目標視窗發送滑鼠按鍵（`WM_LBUTTONDOWN` / `WM_LBUTTONUP` / `WM_RBUTTONDOWN` / `WM_RBUTTONUP`）與鍵盤按鍵（`WM_KEYDOWN` / `WM_KEYUP`）訊息。
- **不搶奪系統焦點、不移動實體游標**，即使遊戲視窗被其他視窗遮擋亦能精準執行。

### 🔀 2. 相對坐標系統與多開支援
- 自動將遊戲視窗客戶區左上角定位為原點 `(0, 0)`。
- 提供 **X / Y 像素級偏差校正**，無視視窗邊框厚度與標題列差異，視窗任意拖動依然點擊分毫不差。

### 📦 3. 動態變數庫 (Dynamic Variable System)
- 支援建立「坐標（Coord）」、「按鍵（Key）」、「停頓等待（Wait）」三類常用變數。
- 具備全域動態引用特性：當遊戲更新或按鍵配置調整時，**僅需修改變數數值一次，全流程與組合技即刻同步生效**！

### ⚡ 4. 技能組合庫與原子性排程 (Combos)
- 支援將連續招式、補血連擊、吃藥拾取等子動作封裝為「技能組合」。
- 具備 **原子完整性保證**：組合技執行期間絕不被其他定時任務插隊打斷，確保連擊一氣呵成。

### ⏱ 5. 定時週期任務與即時倒數雙顯 (Periodic Tasks)
- 獨立週期任務計時排程，可設定每隔固定秒數執行特定技能或組合（如定時補狀態、吃藥、技能防斷）。
- **即時倒數 ＋ 間隔設定值雙重展示**（例如：`⏱ 7s / 每 10s`），任務狀態與剩餘秒數一目了然。
- 支援「開關啟用/停用」及「啟動時立即執行（首）」選項。

### 🔄 6. 無縫熱重載 (Hot Reload)
- 巨集在運行狀態中，使用者依然可以新增、修改、刪除、排序動作與變數。
- 系統透過快照同步機制在背景線程輪詢間隙自動更新執行實例，**完全毋須停止並重新啟動巨集**。

### 📝 7. 100 筆即時色彩標籤日誌 (Execution Log)
- 智慧型色彩標註：區分流程（白）、定時（天藍）、組合（紫色）、系統（綠色）、警示（紅色）。
- 自動保持最新 100 筆紀錄，防止記憶體無限膨脹，並支援自動滾動與一鍵清空。

### 🔒 8. 線程安全狀態架構 (Thread-Safe AppState)
- 全域執行狀態與資料結構全數封裝於 `AppState` 類別中，讀寫均受 `Lock` 保護，徹底杜絕並發競爭與介面凍結。

## 📦 環境需求與安裝說明

### 系統環境
- **作業系統**：Windows 10 / 11 64-bit（唯一支援的執行環境）
- **Python 版本**：Python 3.9 或更高版本

### 安裝步驟

1. **取得程式碼庫**
   ```bash
   git clone https://github.com/kevindiu/autoclicker.git
   cd autoclicker
   ```

2. **安裝所需依賴套件**
   ```bash
   pip install -r requirements.txt
   ```

3. **直接以原始碼啟動**
   ```bash
   python autoclicker.py
   ```

### 封裝為單一可執行檔 (.exe)
本專案已針對 PyInstaller 進行路徑與資源動態適配，可直接使用以下指令進行單檔封裝：

```bash
pyinstaller --noconsole --onefile --icon=app.ico --name="水滸歷險_巨集助手" autoclicker.py
```
打包完成之執行檔將生成於 `dist/水滸歷險_巨集助手.exe`。

## 🚀 使用方式指南

### 步驟 1：綁定目標視窗與開啟後台功能
1. 啟動遊戲客戶端並登入至遊戲主畫面。
2. 啟動本巨集助手，點擊「**↻ 重新整理**」，在「目標視窗」下拉選單中選取您的遊戲視窗。
3. 點擊「**◎ 定位視窗**」，確認視窗置於合適位置。
4. 勾選「**[✓] 背景掛機**」以啟用非干擾背景控制；勾選「**[✓] 相對坐標**」以確保定位精準。

### 步驟 2：建立常用變數庫
1. 在左側「常用變數庫」點擊「**+ 新增變數**」。
2. 選擇變數種類：
   - **坐標 (coord)**：點擊「瞄準取點」，將滑鼠移動至遊戲中指定按鈕或血條位置按空格鍵取點。
   - **按鍵 (key)**：輸入技能快捷鍵（如 `1`、`F1`、`SPACE`）。
   - **停頓 (wait)**：輸入等待時間（秒數，支援小數如 `0.5`）。
3. 建立後可隨時雙擊變數進行數值修改。

### 步驟 3：編排技能組合
1. 在左下方「技能組合庫」輸入組合名稱（例如：`補血連擊`），點擊「**+ 新增**」。
2. 在右側「加入動作」面板中，透過取點、按鍵、停頓或引用變數，逐一加入連擊子動作。
3. 可點擊「**▶ 試跑組合**」單獨驗證連招順暢度。

### 步驟 4：設定主掛機流程與定時任務
1. **主掛機流程**：
   - 選取左側變數或組合，點擊「**➔ 加入掛機流程**」，或在右側「單一動作」面板直接新增。
   - 主流程中的步驟將依序從第 1 步循環執行至最後一步。
2. **定時週期任務**：
   - 在右側點擊「**+ 新增**」定時任務。
   - 設定循環間隔（秒），並選擇欲執行的動作或組合。
   - 勾選「**啟動時立即執行一次**」可讓巨集開始時優先施放此狀態。

### 步驟 5：開始與停止
- 點擊底部醒目的綠色「**▶ 開始循環執行**」大按鈕。
- 按鈕將轉為紅色「**■ 停止執行**」，右下角日誌視窗將開始即時跳出彩色執行記錄。
- 若需緊急暫停，隨時再次點擊該按鈕即可。

## 📄 設定檔格式說明 (.shm)

本工具產生的設定檔採用標準 JSON 結構，副檔名為 `.shm`（水滸歷險巨集 Water Margin Macro）。

### 欄位結構定義

| 頂層欄位 | 型別 | 說明 |
| :--- | :--- | :--- |
| `variables` | `Object` | 全域自訂變數字典，鍵值為變數名稱 |
| `combos` | `Array` | 技能組合清單，每個項目包含組合名稱與其動作序列 |
| `steps` | `Array` | 主掛機循環流程之步驟序列 |
| `periodic_tasks` | `Array` | 獨立計時之定時週期任務清單 |

### 範例設定檔 (`default.shm`)

```json
{
  "variables": {
    "回血技能鍵": {
      "type": "key",
      "value": "f4"
    },
    "主攻技能鍵": {
      "type": "key",
      "value": "1"
    },
    "怪物點擊坐標": {
      "type": "coord",
      "value": {
        "x": 450,
        "y": 320,
        "btn": "left",
        "rel": true
      }
    },
    "攻擊間隔": {
      "type": "wait",
      "value": 0.8
    }
  },
  "combos": [
    {
      "name": "快速補血",
      "actions": [
        {
          "type": "key",
          "var_name": "回血技能鍵"
        },
        {
          "type": "wait",
          "sec": 0.5
        }
      ]
    }
  ],
  "steps": [
    {
      "type": "click",
      "var_name": "怪物點擊坐標"
    },
    {
      "type": "key",
      "var_name": "主攻技能鍵"
    },
    {
      "type": "wait",
      "var_name": "攻擊間隔"
    }
  ],
  "periodic_tasks": [
    {
      "id": "pt_1726200000000_0",
      "name": "定時喝水補狀態",
      "interval": 30.0,
      "enabled": true,
      "run_on_start": true,
      "action": {
        "type": "call_combo",
        "target_name": "快速補血"
      }
    }
  ]
}
```

## 📁 專案模組架構

```
autoclicker/
├── autoclicker.py     # 應用程式主入口與控制器 (App 類別，委派排程與 UI)
├── panels.py          # UI 面板元件 (LeftPanel, RightPanel)
├── config_manager.py  # 設定檔 IO 管理器 (.shm 讀寫、快照對比、Schema 補齊)
├── engine.py          # 動作調度核心 (dispatch_action, execute_single_action, 背景線程控制)
├── state.py           # AppState 全域狀態類別與執行緒鎖 (Thread-safe State Container)
├── widgets.py         # 自訂 UI 組件 (VarTable 變數表格, PeriodicTaskCardView 倒數卡片)
├── dialogs.py         # 對話框基類與編輯彈窗 (變數、動作、定時任務之新增與編輯)
├── win32_api.py       # Windows 底層 API 常數化與訊息封裝 (PostMessage, 視窗列舉, 防卡鍵釋放)
├── theme.py           # 深色科技風色彩常數與字體定義 (UITheme)
├── version.py         # 動態版本偵測 (Git Tag 自動獲取與 PyInstaller 支援)
├── requirements.txt   # Python 依賴清單
└── app.png            # 軟體高解析度主圖標
```
